# Estrutura de Dados em C

Este projeto foi desenvolvido como parte da nota da N3 na disciplina de Estrutura de Software. Ele implementa e compara diferentes algoritmos de ordenação utilizando a linguagem C, com foco em modularidade e boas práticas de programação.

Autores: Ícaro e Gustavo

---

## Objetivo

Implementar e comparar o desempenho de três algoritmos clássicos de ordenação:

- **Bubble Sort**
- **Insertion Sort**
- **Selection Sort**

O projeto visa reforçar o entendimento de estruturas de dados e algoritmos fundamentais, além de práticas de modularização em C.
